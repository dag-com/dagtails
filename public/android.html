DAG Tails for Android

This link always points at the latest nightly APK. GitHub rebuilds it overnight when master has new commits. You do not need to upload a new file.

Download APK

Install

  1. Open the file on an Android phone.
  2. Allow install from this source if Android asks (expected for a non–Play Store APK).
  3. Rotate to landscape — the app is locked that way.

To update later, tap the same download link again. If Android refuses the update, uninstall the old DAG Tails app once, then install this file.
